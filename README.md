# CodeCraftHub — Personalized Learning for Developers
Final Project for IBM "Generative AI: Elevate your Software Development Career" (Module 3: CodeCraftHub — Building Personalized Learning for Developers). Plain HTML/CSS/JS, no frameworks, no build step, no backend.
Files: index.html — page structure; style.css — all styling, including .btn-primary, .btn-success, .btn-danger; script.js — 12-course catalog, personalized recommendations, add / mark-complete / delete, search + filters, progress stats, localStorage persistence; ANSWERS.md — the 4 code snippets for Mark; SUMMARY.md — file list, how to run, test results.
Run locally: python3 -m http.server 8137, open http://localhost:8137/ — or just open index.html directly.
Features: personalization form (interest + level + hours/week), 12 courses across Python, JavaScript, Java, Generative AI, Web Development, DevOps, search + filters, add to My Learning, add custom goals, mark complete, delete, progress stats, localStorage.
